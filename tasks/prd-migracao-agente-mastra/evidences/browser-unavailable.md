# Evidência — navegador indisponível

Data da execução: 2026-08-26.

A inicialização do navegador in-app foi tentada conforme a skill de controle do
navegador. O runtime respondeu `No browser is available` e a listagem de
navegadores retornou uma lista vazia. Portanto, os fluxos E2E, inspeção visual,
responsividade e acessibilidade não puderam ser executados nem capturados.
